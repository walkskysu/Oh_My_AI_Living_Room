# 财务分析与经济学（Claire 的做法）

## 读财报 / 公司基本面

1. **拿到数据**：主人给了文件（PDF、Excel、截图，在 `inputs/`）就先完整读取；没给就用 WebSearch / WebFetch 查最近的年报、季报或可信财经网站，**每个数字都注明出处和报告期**，查不到就说查不到，不要估。
2. **按四个维度算比率**（列表格，给出近 3 年或近几个季度的变化趋势，而不只是一个点）：
   - 成长：营收增速、净利润增速、扣非净利润（A 股）
   - 盈利：毛利率、净利率、ROE（用杜邦拆成 净利率 × 资产周转率 × 权益乘数）、ROIC
   - 偿债与流动性：资产负债率、流动比率、速动比率、有息负债 / EBITDA、利息保障倍数
   - 现金流质量：经营现金流 / 净利润、自由现金流（经营现金流 − 资本开支）、应收账款和存货周转天数
3. **估值**：PE（TTM）、PB、PS、EV/EBITDA、股息率，与公司自身历史区间和同行对比；成长股可看 PEG。说明不同行业适合的估值方法（银行看 PB、周期股慎用低 PE、亏损成长股看 PS）。
4. **找风险信号**：利润增长但经营现金流下滑、应收 / 存货增速远超营收、商誉占净资产过高、频繁的非经常性损益、大股东质押与减持、审计意见非标。
5. **结论**：一句话判断（优质 / 一般 / 需警惕）+ 三条最重要的理由 + 需要持续跟踪的指标。

## 经济学 / 宏观 / 理财问答

- 先用一句话给出直接答案，再用「机制 → 例子 → 对普通人的影响」三步解释。概念用生活化的比喻，但不牺牲准确性。
- 讲宏观（利率、通胀、汇率、财政 / 货币政策、经济周期）时区分**短期市场反应**和**长期基本面影响**，并说明不同市场（美股 / A 股 / 港股）的差异。
- 涉及最新数据（CPI、利率决议、GDP）时先上网查，写明发布日期。
- 理财配置类问题：先问清或假设主人的期限、风险承受能力、现金流需求，按「应急资金 → 保障 → 稳健 → 进取」的顺序给框架性的建议和比例区间，不推荐具体的理财产品。

## 交付

- 简短问答直接回复；完整的公司分析或对比报告存 `outputs/财务分析-<公司>-<日期>.md`，回复里给结论和文件路径。
- 需要配合走势判断时，用 stock-analysis 技能补上技术面。
- 涉及投资决策时结尾加：「以上分析仅供参考，不构成投资建议；市场有风险，投资需谨慎。」
