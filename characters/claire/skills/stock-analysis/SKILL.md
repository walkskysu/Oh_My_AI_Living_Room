# 个股技术分析（Claire 的做法）

## 1. 跑数据脚本

```bash
python .claude/skills/stock-analysis/stock.py <代码或名称> [--weeks 4]
```

- 每次只运行这一条命令本身，不要用 `||`、`&&`、`;`、管道或 `cd` 串起来（无头模式下组合命令会被拒绝）。`python` 不可用时再单独试 `python3`（Windows 上试 `py`）。只用标准库，不需要装任何包。
- 分析多只股票就分别运行多次。
- 代码写法：美股 `AAPL` / `BRK-B`；A 股 `600519`、`sz000001`、`000001.SZ`；港股 `0700`、`00700.HK`、`hk00700`；也可以直接写名称（`腾讯`、`贵州茅台`、`Tesla`），脚本会先搜索。
- 主人没说周期就用默认的 4 周；要求「看两个月」就 `--weeks 8`。
- 脚本输出一个 JSON：`symbol`（解析出的市场、代码、名称、币种）、`last`（最新一根 K 线）、`window`（窗口涨跌、高低点、上涨/下跌天数、趋势斜率与 R²、最大回撤、年化波动率、逐周表现、52 周高低）、`indicators`、`signals`（每条信号带权重，正为多、负为空）、`score`（-100～100）、`verdict`、`levels`（支撑、压力、止损、目标、盈亏比）、`chart`（K 线图 PNG）、`json`（完整数据，含逐日序列）。
- 成交量单位见 `volume_unit`（A 股走腾讯数据源时是「手」）。
- 返回 `error` 时：代码写错就换种写法重试一次（例如加 `.HK` / `sh` 前缀）；网络问题如实告诉主人，**绝不编造价格或指标**。

## 2. 解读（不要只复述分数）

脚本的 `score` 是机械打分，只是起点。你要像分析师一样综合判断：

1. **趋势**：四周涨跌幅、趋势斜率和 R²（R² 高说明走势干净）、均线排列、价格相对 MA20 / MA60 的位置。
2. **动能**：MACD 金叉死叉 / 红绿柱变化 / 背离，RSI、KDJ 的位置（超买超卖只说明短线偏离，不是反转信号）。
3. **量价**：放量上涨还是缩量反弹，上涨日成交是否占优，OBV 方向。
4. **形态与位置**：最近 K 线形态、离支撑/压力多远、布林带开口还是收口、离 52 周高低点多远。
5. **风险**：年化波动率、最大回撤、ATR 占股价的百分比 —— 波动大的票要提醒仓位。
6. 信号互相矛盾时（例如趋势向上但 RSI 超买、量能萎缩），要说清楚哪个更重要、为什么。

## 3. 结论格式

给出三种情景（偏多 / 震荡 / 偏空）的大致概率和触发条件，然后给出明确的操作倾向：

| 倾向 | 适用 |
|---|---|
| **可以考虑买入** | 趋势向上 + 动能确认 + 离支撑近、盈亏比 ≥ 1.5 |
| **等回调再买** | 趋势向上但短线超买 / 离压力太近 / 盈亏比低 |
| **观望** | 方向不明、信号打架、布林带收口等待突破 |
| **不建议买入 / 考虑减仓** | 空头排列、放量下跌、跌破关键支撑 |

写出参考买入区间、止损位、第一目标位（来自 `levels`，可以按你的判断微调并说明理由）。

## 4. 交付

- 简单问一句（「AAPL 能买吗」）：直接在回复里给结论 + 3～5 条关键依据 + 关键价位，并用反引号附上图表路径（脚本返回的 `chart`，例如 `outputs/AAPL-2026-11-20.png`），主人能直接在对话里看到图。
- 要求「详细报告」或一次分析多只股票：另存 `outputs/股票分析-<名称>-<日期>.md`，结构：一句话结论 → 行情概览（表格）→ 趋势 / 动能 / 量价 / 关键价位 → 情景推演 → 操作建议 → 风险提示；图表用 `![](<chart 文件名>)` 引用（md 与 png 同在 outputs/）。多只股票时加一张对比表。
- 结尾固定一句风险提示：「以上为基于历史价格的技术分析，不构成投资建议；市场有风险，投资需谨慎。」
- 技术分析只看价格和成交量。主人问到基本面（财报、估值、行业）时，结合 financial-analysis 技能补充，或说明需要另外查资料。
