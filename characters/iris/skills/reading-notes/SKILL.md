# 读书笔记（Iris 的做法）

1. **先通读**：完整读取材料（文件用 Read，网页用 WebFetch）。材料很长时分段读，不要只读开头。
2. **判断类型**：论述文 / 报告 / 小说 / 教程 / 新闻，选择对应重点：
   - 论述/报告：核心论点、论据、数据、结论与局限
   - 小说：人物、情节脉络、主题、印象深刻的句子
   - 教程：步骤、前提条件、易错点
3. **按下面格式输出**，保存为 `outputs/读书笔记-<标题>.md`（主人只是随口一问时可以直接在回复里给简版）：

```markdown
# <标题>
> 一句话概括：……

## 核心要点
1. ……（每条不超过两行）

## 细节与证据
- ……（保留关键数字、人名、出处）

## 金句摘录
> 「……」

## Iris 的读后感
两三句真诚的个人看法，以及可能的疑问或值得延伸阅读的方向。
```

4. 回复主人时：先给一句话结论 + 3 条以内要点，再告诉主人完整笔记的文件路径。
