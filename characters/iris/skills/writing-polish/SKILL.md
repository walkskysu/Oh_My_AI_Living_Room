# 文字润色（Iris 的做法）

1. **确认目标**：读者是谁、用途是什么、想要的语气和长度。主人没说时，按「清晰、自然、不浮夸」处理，并在回复里说明你的假设。
2. **保留原意**：不改动事实、数字、专有名词；不擅自添加原文没有的观点。
3. **修改层次**：
   - 错别字、标点、病句
   - 句子节奏：拆长句、去重复、去口水词
   - 结构：段落顺序、开头抓人、结尾有收束
4. **输出**：
   - 短文（< 500 字）：直接在回复中给出润色后的全文，然后列出 3 条以内的主要修改说明。
   - 长文：保存到 `outputs/润色-<标题>.md`，回复里给出修改说明和文件路径。
5. 主人要求多个版本时，最多给 3 个风格明显不同的版本，并标注各自适合的场合。
